Regex Basics

Find, replace, and control what gets changed in your chats.

On this page

Back to top ↑

Regexes aren't AI and they don't “think”; they're find-and-replace rules. But they can still change what the AI receives if you tick Alter Outgoing Prompt.

Paste a recipe into Find Regex and Replace With, then tick what it should affect.

What goes in Find Regex

A quick example

Let's say you want to replace every “cat” with “dog”.

Find Regex

/cat/g

Replace With

dog

Original message

The cat sat beside another cat.

Result

The dog sat beside another dog.

The g tells regex to replace every occurrence, rather than just the first.

The letters at the end

Type what you want to find, like cat. To control how it searches, surround the pattern with slashes and add letters at the end. For example, /cat/g finds every occurrence of “cat” instead of just the first.

Use none, one, or several letters together, in any order: /cat/gi is the same as /cat/ig.

Letter / What it does / Without it / Example
Letter What it does Without it Example
Letterg What it doesChanges every place it's found Without itOnly the first one changes Example/cat/g changes both cats in “cat and cat”
Letteri What it doesIgnores capitalization Without itCapitals must match exactly Example/cat/i finds cat, Cat and CAT
Letterm What it doesTreats each line on its own. Needed when a recipe uses ^ or $ Without it^ and $ only match start and end of whole message Example/^Note:/gm finds “Note:” at the start of any line
Letters What it doesLets . match across newlines; recipes here use [\s\S] instead Without it. does not match a newline ExampleCan find a tag spanning lines

Common combinations:

  • /word/g: every one, exact capitalization. This is the usual one.
  • /word/gi: every one, any capitalization.
  • /word/: first one only, exact capitalization.
  • /^text/gm: every line that starts with “text”.

Typing symbols

Letters, numbers and spaces can be typed as they are. Some symbols have special meanings, so typing them as they are quietly finds something else, or nothing:

. * + ? ( ) [ ] { } | ^ $ \ /

To search for one of them as plain text, put \ in front of it.

You want to find / Type / Why
You want to find Type Why
You want to find<word> Type<word> WhyAngle brackets are safe as they are
You want to find</word> Type<\/word> WhyThe slash would end the regex early
You want to findDr. Who TypeDr\. Who WhyA dot means any one character
You want to findReally? TypeReally\? WhyQuestion mark makes the preceding thing optional
You want to find*smiles* Type\*smiles\* WhyAsterisk repeats the preceding thing
You want to find(OOC) Type\(OOC\) WhyParentheses mark a part to reuse in Replace With
You want to find[Status] Type\[Status\] WhySquare brackets match any one of the characters inside
You want to find$5 Type\$5 WhyDollar sign normally anchors the end of the text

The other symbols work the same way: \+ \{ \} \| \^. To find a literal backslash use \\.

What goes in Replace With

  • Type it exactly as you want it to appear. Symbols don't need a backslash here; dollar-number placeholders and macros are special.
  • $1 puts back whatever the first capture group () found; $2 uses the second. Use only numbered groups you actually created.
  • {{match}} puts back the entire matched text.
  • Macros like {{char}} and {{user}} are filled in.
  • In Replace With, $5 means “insert capture group 5.” If there is no fifth group, SillyTavern removes it instead of showing the price. To find a literal $5 in Find Regex, use \$5; finding a price and inserting one are different things.
AI-generated Regex Advice

LLMs might suggest standard JavaScript replacement syntax, which doesn't always work in SillyTavern because it handles replacements differently. Don't assume an LLM understands SillyTavern's replacement rules just because it says it does.

Recipes

Each recipe has two parts. Put the first in Find Regex and the second in Replace With.

To do this / Find Regex / Replace With
To do this Find Regex Replace With
To do thisReplace a word Find Regex/native/g Replace Withnatural
To do thisReplace regardless of capitalization Find Regex/native/gi Replace Withnatural
To do thisWhole word only Find Regex/\bnative\b/g Replace Withnatural
To do thisPreserve first-letter capitalization Find Regex/\b([Nn])ative\b/g Replace With$1atural
To do thisRemove a tagged block, tags included Find Regex/<thinking>[\s\S]*?<\/thinking>/g Replace WithLeave empty
To do thisRemove a tagged block with extra details, like <status mood="happy"> Find Regex/<status\b[^>]*>[\s\S]*?<\/status>/g Replace WithLeave empty
To do thisKeep inside text, remove tags Find Regex/<b>([\s\S]*?)<\/b>/g Replace With$1
To do thisRemove a line containing specific text Find Regex/^.*Word count:.*$\n?/gm Replace WithLeave empty
To do thisWrap a name in bold Find Regex/\bJohn\b/g Replace With**{{match}}**
  • [\s\S]*? means any text, including across lines, stopping at the first possible closing tag.
  • Preserving capitalization only works for the two cases shown. For uppercase NATIVE, add a second regex: /\bNATIVE\b/g → NATURAL.
  • Whole-word matching using \b can have problems with letters such as é.

HTML & CSS Basics

HTML and CSS let you customize how text appears in SillyTavern, from simple formatting like bold and italics to styled boxes.

For example, <strong>John</strong> makes John bold, but only where that HTML is written. You can use regex to automatically apply the same formatting to every occurrence of John.

Find Regex / Replace With
Find Regex Replace With
Find Regex/\bJohn\b/g Replace With<strong>{{match}}</strong>

The \b means whole word only, so John gets formatted without affecting Johnson or Johnny. The <strong> tags make the matched text bold.

Common HTML formatting

HTML uses tags to tell the browser how to display content. Most formatting tags have an opening and closing tag, such as <em> and </em>.

HTML & CSS together

Suppose the AI writes:

<char_stats>
Health: 80/100
Mood: Curious
</char_stats>

Result

Character Status

Health: 80/100

Mood: Curious

You can use regex to turn that tagged text into a styled box.

Find Regex

/<char_stats>([\s\S]*?)<\/char_stats>/g

Replace With

<div style="background: #332335;
            color: #ffe6f1;
            border: 1px solid #b77a9a;
            border-radius: 8px;
            padding: 12px;">
  <strong>Character Status</strong>
  <p style="white-space: pre-line;">$1</p>
</div>

The <div> creates the box, while style controls its colors, border, rounded corners, and spacing. $1 inserts the text captured between the <char_stats> tags, and white-space: pre-line preserves its line breaks.

What It Changes

The two Ephemerality boxes decide what gets changed:

Alter Chat Display / Alter Outgoing Prompt / Result
Alter Chat Display Alter Outgoing Prompt Result
Alter Chat DisplayOff Alter Outgoing PromptOff ResultChanges the saved message permanently. New messages are affected when they arrive, and edited ones when Run On Edit is enabled.
Alter Chat DisplayOn Alter Outgoing PromptOff ResultChanges what you see. The saved message and AI prompt stay the same.
Alter Chat DisplayOff Alter Outgoing PromptOn ResultChanges what the AI receives. The display and saved message stay the same.
Alter Chat DisplayOn Alter Outgoing PromptOn ResultChanges the display and AI prompt, but not the saved message.
Visual regexes: tick only Alter Chat Display

For regexes that add HTML, images or colors, untick Alter Outgoing Prompt. Otherwise the AI also receives the formatting code, wasting tokens and possibly affecting its responses. Leaving both unticked saves that code into the message itself.

Affect and Depth

  • Affects: which kinds of text it runs on (AI Output, User Input, Slash Commands, World Info, Reasoning).
  • Min Depth: skip a number of recent messages, then apply to older messages.
  • Max Depth: apply to the newest message and up to the selected depth.
  • Leave a depth box empty (Unlimited) for no limit.
Min Depth / Max Depth might affect prompt caching

Some APIs reuse the unchanged beginning of your prompt at a discount. If a regex changes an older message each turn, everything from that message on may be sent at full price.

  • Small depth ranges often limit the impact.
  • For Claude, compare your chosen depth against your configured cachingAtDepth.
  • Unlimited depth is generally more stable for caching when replacements and macros produce the same output each turn.

Other Settings

  • Trim Out: words removed from the found text before $1 or {{match}} puts it back. Usually left empty.
  • Macros in Find Regex:
    • Don't substitute: looks for the literal letters {{char}}.
    • Substitute (raw): looks for the character's name instead.
    • Substitute (escaped): likewise, but escapes regex symbols in the name, such as the dot in “Dr. Who”.
