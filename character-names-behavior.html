Why does it exist?

When you're talking to one character, it's usually easy for the AI to follow along. But what if you're chatting with Homelander and Butcher at the same time?

The API identifies messages as coming from the user or assistant, but that doesn't always tell it which character spoke. Character Names Behavior controls how SillyTavern adds speaker names to messages sent to the AI.

What do the four options do?

They control whether SillyTavern adds speaker names and where those names go.

OptionWhat it doesThink of it as...
NoneDoesn't add extra speaker-name labels through this setting.Leaving off the contact name.
DefaultAdds names selectively, particularly when groups or different personas need them.Adding contact names when useful.
CompletionPuts the name in a separate API name field, where supported.A contact label attached to the message rather than inside its text.
Message ContentAdds the name to the actual message text.Writing Homelander: I can fly. inside the bubble.

Different API providers support speaker names differently. That's one reason SillyTavern gives you several options.

What should I use?

For beginners, start with None. In an ordinary one-on-one chat, the API already separates your messages from the AI's, so you usually don't need SillyTavern to add character-name labels.

If you're using group chats or switching personas and the AI gets confused about who's speaking, try Default.

Completion and Message Content are worth trying only when you have a specific reason to change how names are sent.

Important: This affects the messages sent to the AI, not the names displayed in SillyTavern's chat window.
