What does Squash System Messages do?

System messages carry instructions for the AI. SillyTavern can send them separately, but Squash System Messages joins neighboring System messages together into one System message.

Imagine giving Homelander three instruction notes. Instead of handing him three separate sheets, you put them on one sheet. The instructions are still there; only the packaging has changed.

What the AI receives

Only consecutive System messages are joined. If a User or Assistant message separates them, Squash does not reach across that message to combine them. Example Dialogue is excluded.

How does it compare with PPP?

The closest Prompt Post-Processing (PPP) option is Merge consecutive messages from the same role. They work similarly, but PPP's Merge option can also combine neighboring User messages or neighboring Assistant messages.

Squash System Messages

System + System becomes one System message. Other roles aren't merged by this setting.

PPP: Merge consecutive messages

System + System, User + User, or Assistant + Assistant can be combined when the role matches.

See the Prompt Post-Processing guide for a fuller explanation of how PPP formats messages.

Why does this setting exist?

Squash System Messages is an older option for packaging instructions. Some AI APIs have restrictions on how System messages can be arranged, so combining them can help with compatibility.

PPP later provided more flexible ways to organize messages, which is why the two settings seem to overlap. SillyTavern now marks Squash System Messages as deprecated and recommends using PPP instead.

Should I enable it?

For beginners, leave it off. Most people don't need to change this setting. If your AI API needs a particular message format, use the appropriate PPP setting instead.

Combining messages does not automatically make the AI follow instructions better. It changes how the instructions are sent, rather than what they say.
