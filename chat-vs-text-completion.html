Chat Completion vs Text Completion

Both let you talk to an AI. So why does SillyTavern have two different ways to send a conversation?

What's the difference?

Imagine Anya is roleplaying with Homelander. She asks him how to bake a cake, and SillyTavern sends the conversation to an AI.

Chat Completion sends separate messages with roles attached. The API can distinguish a System instruction, a User message, and an Assistant reply.

Text Completion sends a continuous piece of text. The AI reads what's written so far and generates what comes next. Names and special formatting can tell it who's speaking.

It's the difference between sending a conversation as individually labeled messages and handing over a script with a blank space at the end.

These are simplified illustrations, not a promise that every provider receives exactly this wording. SillyTavern can include character details, chat history, lorebook entries, and other instructions in the prompt too.

Can Text Completion still understand roles?

Yes. Text Completion doesn't require the conversation to look like a screenplay. SillyTavern's Instruct Mode can add special markers that show where instructions and messages begin and end.

For example, a ChatML-style template can use markers such as <|im_start|>user and <|im_end|>. These markers are part of the text prompt rather than separate API role fields.

The important part is choosing formatting that matches what your model expects. Different models can use different templates.

Where are the settings?

With Chat Completion, you'll usually manage the prompt through Prompt Manager. With Text Completion, look under Advanced Formatting for the Context Template and Instruct Mode settings.

These controls matter because they affect how SillyTavern prepares the prompt before it reaches your model.

Which should I use?

If your model supports both formats, feel free to experiment! Otherwise, or if you're unsure where to start, use the API format recommended for your model and backend.

Even when both are supported, performance can differ significantly depending on how prompts are formatted. A model that roleplays beautifully with one setup might struggle with the other.
