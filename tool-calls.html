Tool Calls

How an AI asks another program for help, and what actually happens when it does.

What is a tool call?

Imagine the AI as a receptionist. You ask, “What’s 2 + 2?” They already know the answer. But if you ask, “Has my package arrived?” they contact the mailroom, get the answer, and tell you.

The AI works similarly: it can answer directly or request help when a suitable tool is available. A tool call is when the AI requests that another program perform a specific job. SillyTavern or a compatible integration runs that tool, returns the result, and the AI can use it to reply.

1

“Has my package arrived?”

2
The AI requests a tool

The receptionist asks the mailroom to check. In SillyTavern, the AI requests a tool. That request is the tool call.

↓
3
The tool does the job

The mailroom checks and reports back. In SillyTavern, software runs the tool and returns its result.

↓
4
The AI replies to you

“Yes, your package is here!”

The receptionist and mailroom are an analogy. Real tool calls use structured requests to software, not phone calls.

Important distinction

The AI asks for a tool to run. The tool itself is executed by software, rather than magically happening inside the model. The AI may then receive the output as additional conversation information.

⚠ Do tool calls cost extra?

They can! Tool calls may use extra tokens and API requests, which can increase your costs. Some tools also charge their own fees.

Where do I turn it on?

In SillyTavern, the setting is named Enable function calling. “Function calling” and “tool calling” refer to the same general feature here.

  1. Choose a supported Chat Completion API connection and model in API Connections.
  2. Open AI Response Configuration (the sliders icon).
  3. Find Prompt Manager → Utility Prompts.
  4. Enable Enable function calling.
  5. Make sure a compatible extension or feature actually provides a tool, with any tool-specific activation option enabled when required.

Simply switching on function calling does not install a web browser, calculator, or other tools. It permits eligible tools to be offered to the model. The model still decides whether to request one, subject to the tool and prompt.

Don't see any tool calls?

Check the API type, the selected model's tool support, whether a tool-providing feature is installed and configured, and whether your message gives the model a reason to use it.

Chat Completion or Text Completion?

Chat Completion

Native tool calling: Yes, when supported.

Compatible API sources and models can send structured tool-call requests to SillyTavern.

Text Completion

Native tool calling: No.

SillyTavern's Text Completion API mode does not support its native function-calling feature.

A local model does not automatically mean Text Completion. Some locally hosted backends can be connected using a Custom OpenAI-compatible Chat Completion endpoint.

What tools might be available?

Tools come from supported features, extensions, and integrations. They need to be configured for the job they perform.

These are examples of capabilities, not a promise that they're all available in your installation.

How does this relate to Prompt Post-Processing?

Your Prompt Post-Processing (PPP) setting affects how SillyTavern prepares messages for certain Chat Completion APIs. Tool calls can become part of that conversation history.

PPP choiceWhat happens to tool-call information?
NoneDoesn't explicitly strip tool calls as a PPP action. API-specific processing may still apply.
With Tools variantPreserves tool-call information when using the applicable merging/conversion mode.
No Tools variantRemoves tool-call information. Native tool calling is not supported with this variant.

So “No Tools” is not just a cosmetic setting. It matters when the AI needs to keep track of tool requests and results.

Common questions

Does turning this on mean the AI will always use a tool?

No. The tool must be available and supported, and the AI must decide to request it. Some generations, including continuations, impersonation, and quiet/background generations, cannot trigger tool calls in SillyTavern.

Can a tool call use multiple steps?

Yes. A model may request another tool after receiving an earlier result. SillyTavern has a configurable tool-calling recursion limit, with a documented default of five rounds, to stop indefinite loops.

Will I see tool calls in chat?

Usually, successful tool calls are recorded in chat history and can be inspected. Extension developers can also register a tool as “stealth,” which changes whether the tool result appears as a visible chat-history item.

Is a normal message mentioning a tool the same thing?

No. Saying “I searched the web” is just text. A real tool call is a structured request handled by a supported tool-running system. Check for an actual tool result rather than trusting a claim in the AI's message.

Is tool calling the same as slash commands?

No. A slash command is typically an instruction you run through SillyTavern's command system. In native function calling, the model chooses to request an offered tool during generation.
