What is a Seed?

When the AI writes a reply, it has many possible words to choose from. A Seed is a number used to start the randomness involved in making those choices.

By choosing a particular Seed, you can sometimes make the results repeatable. This is especially useful when you're testing settings and want to compare what changed.

Imagine shuffling a deck of cards

Picture a deck of cards. Each shuffle gives you an order. A fixed Seed is like asking for a particular shuffle again, while -1 means asking for a fresh shuffle.

A♥K♠7♦2♣

Choose a Seed, then shuffle. With a fixed Seed, repeating the shuffle gives you the same order in this example.

Try it: Select 12345 and click Shuffle cards twice. You'll see the same order both times. Then choose -1 and shuffle again.

What do the numbers mean?

SeedWhat happens
-1Use fresh randomness rather than a fixed Seed. This is the usual choice for everyday chats.
12345Use a specific starting point for randomness, which may help reproduce a result.
67890Use a different starting point. The result might change, but a different number doesn't guarantee a different reply.

There's nothing special about those numbers. A larger Seed won't make the AI smarter, more creative, or better at roleplaying.

Should I change it?

For normal roleplaying, leave Seed at -1. Most people don't need to touch it.

A fixed Seed can help when you're experimenting. For example, you might keep the Seed the same while changing Temperature, so there's one less source of variation while you compare the replies.

Keep in mind: A fixed Seed doesn't guarantee the exact same AI response. The prompt, model, sampler settings, and API backend can all affect the result. Some providers may ignore the Seed entirely.

If you're curious about Temperature and the other controls, see the Sampler Settings guide.
